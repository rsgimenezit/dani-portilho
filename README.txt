COMO PUBLICAR NO GITHUB PAGES
1. Crie um repositório no GitHub, por exemplo: dani-portilho
2. Envie todos os arquivos deste ZIP para a raiz do repositório.
3. No GitHub, acesse Settings > Pages.
4. Em Build and deployment, escolha "Deploy from a branch".
5. Selecione a branch "main" e a pasta "/ (root)".
6. Clique em Save.
7. Aguarde alguns minutos. O endereço ficará parecido com:
   https://SEU-USUARIO.github.io/dani-portilho/
